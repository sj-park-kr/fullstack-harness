## 새 패인 (공통)
1. **M1이 최종 산출물에서 끝나지 않는다.** M1을 "AI 파이프라인"으로 정해 사용자가 손에 쥐는 결과(요구서·독촉 편지)와 미션 증거 화면(1인 운영 콘솔)이 Phase 2 밖으로 밀렸다. 6명 전원 지적.
2. **실사용 증거를 구할 경로가 없다.** 검색이 막히면 끝. 대체 출처, 팀 직접 경험, 당일 인터뷰 작업이 없다.
3. **AI 깊이가 해자로 안 보인다.** 정확도 평가나 잡아낸 오류를 보여 주는 화면이 없다.
4. 1번: 에이전트 규모(2개 대 우승작 10개), 파트너 기술 0점.

## 하네스 버그
- CLI 사용량 한도 시 종료 코드 0 + `is_error:true` + 한도 문구가 `result`로 와서 AI 답으로 화면에 뜰 수 있다(design).
- 숫자 고정용 memo가 적중하면 `source=cli`, 0ms로 나와 qa가 실제 호출 없이 통과(design, qa).
- 티켓 상태 줄 형식 불일치: tracker 문서 `Status:` vs build-plan `**Status:**`.
- 스크린샷이 최종 배포 때만 `plan/shots/`로 복사돼, 중간에 멈추면 `/judge-review` 입력이 빈다(orchestrator).
- 시간 규칙 충돌: planning NOTES(자동 압축 금지) vs plan-orchestrator(5분 넘으면 압축). build-plan은 실제 시계를 봐 리허설에서도 승인을 건너뜀.
- CLI 호출당 시스템 컨텍스트 ~11k 토큰(최소 약 $0.046). 스모크가 페이지 열 때마다 돎.
- Windows 경로 길이 제한: anthropic 최신판 설치 실패, builder가 레포 밖에 venv 생성. qa `>> log`로 file in use. "cli" 부분 문자열 검사가 "Client"에 걸림.
- 사용량 한도(429)로 architect가 약 3시간 중단. /design에 재개 안내 없음.

## 잘 된 것
- 로컬 티켓 흐름: ready-for-agent → claimed → resolved, Blocked by로 다음 티켓 선택, qa 결과·재현 단계가 `## Comments`에 남음.
